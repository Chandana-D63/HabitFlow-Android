# HabitFlow Project Brief

HabitFlow is a production-ready habit tracking application designed to help users build consistency through a modern, responsive, and location-aware experience. It leverages the latest Android technologies to ensure reliability and a premium Material Design 3 aesthetic.

## Features
*   **Habit Management & Tracking:** Create, edit, and track daily habits with a simple check-in system and streak counters to maintain motivation.
*   **Location-Based Reminders:** Integrated Google Maps functionality allows users to set reminders triggered by specific locations (e.g., "Gym" or "Library").
*   **Offline-First Experience:** Full functionality without an active internet connection using robust local data persistence.
*   **Progress Analytics:** Detailed visual insights and statistics to monitor habit consistency over time.

## High-Level Technical Stack
*   **Language:** Kotlin
*   **UI Framework:** Jetpack Compose with Material Design 3
*   **Navigation:** Jetpack Navigation 3 (State-driven)
*   **Adaptive Layouts:** Compose Material Adaptive library (supporting various screen sizes)
*   **Concurrency:** Kotlin Coroutines & Flow
*   **Local Persistence:** Room Database (for offline support)
*   **Location Services:** Google Play Services Location & Maps SDK
