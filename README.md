# HabitFlow-Android
# 📱 HabitFlow – Smart Habit Tracking Android Application



## 📖 Overview

**HabitFlow** is a modern Android application designed to help users build positive habits, monitor their daily progress, and improve productivity through an intuitive and user-friendly interface.

The application provides an organized way to create, manage, and track daily habits while offering a clean Material Design 3 interface, responsive layouts, and a seamless user experience.

This project was developed as part of the **60-Day Android Development Internship** at **ApexPlanet Software Pvt. Ltd.**


```
File
```

```
Sync Project with Gradle Files
```
