# Product Requirements Document

## Project Name
HabitFlow

## Problem Statement
Many people struggle to maintain consistency in their daily habits.

## Objective
Build an Android application that helps users create, track, and maintain habits.

## Features
- Add Habits
- Edit Habits
- Delete Habits
- Daily Tracking
- Progress Statistics

## Target Users
Students, professionals, and self-improvement enthusiasts.

## Future Enhancements
- Cloud Sync
- Notifications
- Analytics Dashboard
